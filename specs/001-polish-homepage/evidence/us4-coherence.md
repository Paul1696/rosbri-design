# US4 — Coherence and shared navigation

The shared header and mobile-menu sources were audited; their catalogue/search/cart routes and focusable controls already satisfied the homepage contract, so no fallback mirroring change was required. Section rhythm, widths, typography, cards, buttons and responsive stacking are normalized in `home.css`. Browser checks at all five viewports found no horizontal overflow. Reduced-motion rules preserve visible content without transforms.
